Add it in a few steps.

  1. Extract the ZIP and keep lower-third-1080p.html in a permanent folder.
  2. In OBS: Sources → + → Browser. Create a new source, enable Local file and choose the HTML.
  3. Set Width 1920 and Height 1080. Leave Custom CSS empty. Reset the source transform and place it above the content it should cover.
  4. Record a short local test and inspect the saved output. After editing the file, refresh it in source properties.

To change the sample's words, open the HTML in a plain text editor. Edit the text inside the eyebrow, heading and subtitle tags; keep the tags intact. Read the complete sample notes for escaping special characters and matching a smaller canvas.
